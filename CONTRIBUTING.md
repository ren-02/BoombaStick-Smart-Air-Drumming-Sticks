# Contributing to BoombaStick

Thanks for your interest in contributing to BoombaStick! 🥁

## How to Contribute

### Reporting Bugs
- Open an [Issue](../../issues) with a clear description of the problem.
- Include your hardware setup (Arduino board, BNO055 wiring, etc.).
- Paste any Serial Monitor output if relevant.

### Suggesting Features
- Open an Issue tagged with `enhancement`.
- Describe the feature and why it would be useful.

### Submitting Code
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Commit your changes: `git commit -m "Add my feature"`
4. Push to the branch: `git push origin feature/my-feature`
5. Open a Pull Request.

### Adding Drum Samples
- Place `.wav` files in the appropriate subdirectory under `host/SAMPLES/`.
- Use 44100 Hz sample rate for best compatibility.
- Keep file sizes reasonable (under 1 MB per sample).

## Code Style
- **Arduino (C++)**: Use 2-space indentation and descriptive variable names.
- **Python**: Follow [PEP 8](https://peps.python.org/pep-0008/).

## Questions?
Open an Issue — we're happy to help!
